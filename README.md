# Recipe Book

This application is a recipe book that allows users to create, view, and manage
their favorite recipes.
User can add new recipes, edit existing ones, and delete recipes they no longer
want.
The application also allows users to search recipes by ingredients, cuisine type,
or name.
Users can also categorize recipes into different sections.

## Features

- Add new recipes with details such as ingredients, instructions, and cooking time.
- Edit existing recipes to update information or correct mistakes.
- Delete recipes that are no longer needed.
- Search for recipes by name, ingredients, or cuisine type.
- Categorize recipes into different sections for easy organization.

## Installation

Download the application from google play store or apple app store and install
it on your device.

## Usage

1. Open the application on your device.
2. To add a new recipe, click on the "Add Recipe" button and fill in
   the required details such as recipe name, ingredients, instructions, and
   cooking time.
3. To view a recipe, click on the recipe name from the list of recipes.
4. To edit a recipe, click on the "Edit" button next to the recipe you
   want to update, make the necessary changes, and save.
5. To delete a recipe, click on the "Delete" button next to the recipe you want
   to remove.
6. To search for recipes, use the search bar at the top of the screen and enter
   the recipe name, ingredient, or cuisine type you are looking for.
